# 篮球集锦 Windows 预览版

[下载 Windows 预览版](https://github.com/panta1209/basketball-highlights/releases/tag/v0.1.0-preview.1)

从本机篮球视频中寻找进球，人工核对后生成保留原声的集锦。识别和剪辑全部在电脑本地执行，不需要账号、远程服务器或系统 Python。

## 使用

1. 完整解压压缩包。不要在压缩软件内直接运行。
2. 双击 `BasketballHighlights.exe`。保留启动窗口。如果提示缺少微软运行组件，点击“安装微软运行组件”，完成微软官方安装后继续。此步骤首次可能需要联网和 Windows 安装授权。
3. 在自动打开的本机页面选择视频，等待识别完成。
4. 打开复核页面，确认待确认项。自动计入的片段也可以移除。
5. 发现漏球，点击“补一个漏掉的进球”。在原视频中定位，填写进球时刻、片段开始和结束时间。时间单位为秒。
6. 需要改变保留长度时，点击相应片段的“调整片段范围”。
7. 点击“导出全部已选进球”，完成后下载 MP4 集锦。

关闭网页不会主动停止识别。关闭启动窗口会停止本软件和正在执行的任务。中断任务会保留记录，重新打开后需重新提交视频；v0.1 尚不支持从中断帧继续。

## 当前支持范围

- Windows 10/11，64 位。使用电脑 CPU 处理。
- 固定机位或轻微晃动、篮网清楚可见的视频。当前验证以既有三分钟视频为主。
- 无人物识别、人物分组和个人集锦。
- 识别仍可能误报或漏球。人工确认和补充单独保存，不作为自动识别的准确率。
- 旋转元数据、可变帧率、剧烈移动或篮筐过小时，可能无法分析。软件会显示未能处理，不将其视为零进球。
- 输入文件上限为 8 GB；导入会在本机任务目录保存副本。请预留输入副本和导出视频所需空间。长视频的速度与稳定性尚未完成验收。

## 本机文件

“打开本机任务文件夹”可查看任务。默认目录为用户本机应用数据目录下的 `BasketballHighlights`。其中 `jobs` 保存输入副本、分析和导出，`app.log` 保存运行错误。删除软件目录不会自动删除这些任务。草稿保存在当前浏览器中，清除浏览器数据会移除尚未导出的草稿；已导出的视频和选择记录仍保留在任务目录。

首次启动使用本机浏览器显示界面，地址为 `127.0.0.1`。本机处理服务只监听此回环地址，不对局域网开放。微软运行组件齐全后可断网使用；缺少时，首次准备需从微软官方联网取得固定版本。软件会核对下载文件的 SHA-256。不会通过网络识别或剪辑视频。

## 开发构建

源码以 AGPL-3.0 发布。第三方组件保留各自的许可证，见 `THIRD_PARTY_NOTICES.md` 与发行包内的 `licenses`。模型的固定来源与 SHA-256 保存在 `third_party` 来源清单内。

准备 Windows x64 Python 3.12、CPU PyTorch、锁定依赖，以及 FFmpeg/ffprobe。执行：

```powershell
python scripts/fetch_release_model.py
python -m pip install -r requirements-windows.lock.txt
python scripts/build_windows_portable.py --out dist/BasketballHighlights --ffmpeg-home <FFmpeg解压目录> --license-sources <对应源码目录>
```

构建程序不会下载模型或修改驱动。输出目录必须不存在。Python 解释器必须是可以整体搬移的独立发行版；系统安装版或虚拟环境的重定向解释器不能单独复制代替完整运行时。每次构建保留源码版本、文件 SHA-256、组件版本和许可证。

## Android

Android 完整应用延期。已有 APK 仅为本地目标检测样机，尚未包含完整进球复核和集锦导出，不作为本版本的手机产品。

源码使用的模型不直接放进 Git 历史，由下载脚本从固定来源取得并校验。公开构建使用 `scripts/build_windows_media.sh` 从固定 FFmpeg/x264 源码构建视频工具；对应源码归档和 OpenCV LGPL 解码组件源码随便携包提供。

v0.1 的已完成任务暂与原解压目录关联，处理视频后请保留该目录。更换目录后的新任务可正常建立，跨安装目录迁移旧任务仍需后续完善。开发电脑上的既有三分钟视频已通过导入、识别、复核和原声导出；尚未在全新 Windows 系统和更多长视频上验收。
